# zapret-ui

**Удобный графический интерфейс для обхода DPI-блокировок на Windows и macOS Apple Silicon.**

Установка ядра, выбор стратегии и запуск обхода — в одном интерфейсе, без командной строки.

## 💡 Что это

Одно приложение на Rust + Slint для **Windows 10/11 x64** и **macOS 14+ Apple Silicon**. Интерфейс подключения, настройки, тест стратегий, логи и Telegram proxy развиваются вместе в одном репозитории. Приложение само загружает ядро для вашей системы и читает его актуальные стратегии.

| Платформа | Ядро обхода | Файлы одного релиза |
|---|---|---|
| Windows 10/11 x64 | [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) — `winws.exe`, пресеты `.bat`; опционально [bol-van/zapret2](https://github.com/bol-van/zapret2) (бета) — `winws2.exe`, Lua и пресеты JSON | `zapret-ui.exe` |
| macOS 14+ Apple Silicon | [Flowseal/zapret-mac-discord-youtube](https://github.com/Flowseal/zapret-mac-discord-youtube) — `utunws`, каталог TSV | `zapret-ui-macos-arm64.dmg` или `.zip` |

Новые релизы содержат обе сборки с одной версией и SHA-256 для каждого файла. Intel Mac и Linux пока не поддерживаются. Ядра скачиваются отдельно из приложения.

|  |  |
|---|---|

| 🎯 **Готовые и пользовательские стратегии** | zapret1 и Mac читают пресеты ядра; для zapret2 установщик создаёт три стартовых JSON-пресета и поддерживает пользовательские варианты. |
| 🪄 **Простой и полный режимы** | Компактное подключение или панель со стратегией, службой, фильтрами и версиями; выбранный режим сохраняется. |
| 🧪 **Автоподбор стратегии** | Встроенный тест проверяет пресеты выбранного ядра и показывает результаты по мере их появления. |
| ▶️ **Запуск одной кнопкой** | Windows: процесс или системная служба. macOS: системная служба launchd, которая продолжает работать после выхода из GUI. |
| 🔄 **Обновления** | Ядро обновляется из приложения на обеих платформах. Приложение: встроенное обновление на Windows, замена `.app` на macOS. |
| ⚙️ **Тонкая настройка** | IPSet и пользовательские списки; игровой фильтр и автоматические операции hosts доступны для Windows zapret1. |
| 📋 **Логи и интерфейс** | Тёмная/светлая тема, RU/EN, журнал событий, трей Windows и строка меню macOS. |
| ✈️ **Telegram proxy** | Встроенный локальный MTProto → WebSocket прокси, страница в приложении и подключение Telegram одной кнопкой. |

## 🚀 Установка

### Windows

1. Скачайте **`zapret-ui.exe`** из раздела [**Releases**](https://github.com/meldxkviel/zapret-ui/releases/latest).
2. Запустите. Установка не требуется — всё в одном файле.

> [!WARNING]
> При запуске Windows запросит права администратора (UAC) — это необходимо: обходу нужен драйвер WinDivert, а тесту стратегий и работе со службой нужны права.

### macOS 14+ (M1 или новее)

1. Скачайте **`zapret-ui-macos-arm64.dmg`** из [Releases](https://github.com/meldxkviel/zapret-ui/releases/latest).
2. Откройте образ, перетащите **Zapret UI** в **Applications** и запустите оттуда. Доступен также ZIP с тем же `.app`.
3. Установите ядро и запустите стратегию из интерфейса. Подтвердите системный запрос администратора.

GUI работает без повышения прав: не запускайте его через `sudo`. Администратор нужен только для системных операций ядра.

Сборка имеет локальную подпись, без нотарификации Apple. Если macOS блокирует первый запуск, разрешите его через **Системные настройки → Конфиденциальность и безопасность → Открыть всё равно**. [Подробная инструкция и сборка из исходников](docs/macos.md).

## 🕹️ Как пользоваться

В заголовке **Панели** выберите **Простой** или **Полный** режим. Приложение сохраняет этот выбор, в том числе из существующего конфига.

В **простом режиме** нажмите **Установить и подключить** или **Подобрать и запустить**: приложение при необходимости скачает выбранное ядро, проверит его стратегии и оставит подходящую запущенной.

В **полном режиме** основная кнопка запускает выбранную стратегию, а автоподбор доступен отдельной кнопкой **Подобрать и запустить**. Здесь сразу показаны версии приложения и ядра, последняя доступная версия, число стратегий, время работы, режим процесса и PID. Ниже находятся служба, описание стратегии, доступные для ядра фильтры и быстрые действия установки, обновления и открытия папки. Ручной выбор доступен через **Выбрать вручную** или **Сменить стратегию**.

Во время установки панель показывает ядро и прогресс загрузки; при подборе — текущего кандидата и кнопку отмены. Для работающего обхода основная кнопка меняется на **Остановить обход**. На Mac при проверке кандидатов могут повторяться системные запросы администратора.

На Windows выбор ядра всегда доступен на **Панели** и в **Настройках → Ядро обхода**:

- **zapret1** — существующий Flowseal-дистрибутив с `.bat`-стратегиями.
- **zapret2 · Бета** — официальный `winws2.exe` с Lua-библиотеками, отдельной установкой и JSON-пресетами. Выбор этой кнопки включает использование zapret2; отдельного переключателя бета-функции нет. Если ядро отсутствует, установите его из панели или настроек.

По умолчанию используется zapret1. Автоподбор работает **только внутри выбранного ядра**. Перед тестом стратегий остановите текущий обход. Проверка сначала измеряет сеть без обхода, затем последовательно проверяет кандидатов и оставляет лучшую подходящую стратегию запущенной. На странице **Тест стратегий** результаты появляются по мере проверки: ядро, задержка и изменения доступности относительно исходной проверки. Подбор с панели и подробный тест используют эту же страницу результатов. Одновременно два ядра не запускаются.

Выбор ядра доступен и во время подбора: смена ядра сначала отменяет проверку и дожидается её завершения. Она также останавливает обход и удаляет принадлежащую приложению службу другого ядра, чтобы Windows не запустила её при следующей загрузке. Для автозапуска нового ядра установите службу повторно. [Пользовательские пресеты, сохранение файлов и ручная проверка](docs/zapret2.md).

**Статус проверки zapret2:** в среде разработки антивирус Windows заблокировал официальный ZIP. Настоящие `winws2.exe`, обход DPI и запуск zapret2 через SCM здесь не проверялись. Добавлены автономные проверки и тесты с моками; они не подтверждают работу у конкретного провайдера. macOS-сборка и нативные проверки Mac в рамках этой Windows-интеграции не выполнялись.

Если обход не помогает у вашего провайдера, попробуйте другой пресет и проверьте нужные сайты и приложения. На Windows доступен запуск процессом или службой SCM; на macOS ядро всегда работает как системная служба launchd. Служба ядра может работать после полного выхода из GUI. Telegram proxy работает только пока запущено приложение. Автозапуск GUI при входе в систему и автозапуск Telegram включаются отдельно в настройках.

### Telegram proxy

1. Откройте **Telegram proxy** синей кнопкой внизу бокового меню, над индикатором состояния → **Включить прокси**.
2. Нажмите **Подключить в Telegram** и подтвердите добавление прокси в клиенте.
   Если клиент не открылся, используйте **Скопировать ссылку**.
3. Оставьте zapret-ui открытым или свёрнутым в трей Windows / строку меню macOS. После остановки прокси
   отключите его в настройках Telegram, чтобы вернуться к обычному подключению.

Кнопка **Настройки прокси** внизу страницы открывает порт (по умолчанию 1443),
секрет MTProto, адреса WebSocket по DC, резервное TCP-подключение, тайм-аут и
лимит соединений. Настройки меняются при остановленном прокси. Пустой секрет
при сохранении заменяется случайным; после изменения порта/секрета добавьте
подключение в Telegram заново. Доступ только с текущего компьютера (`127.0.0.1`).

В настройках можно скрыть Telegram из бокового меню: это остановит прокси и
отключит его автозапуск. По умолчанию прокси выключен при открытии приложения;
при желании включите отдельную настройку автозапуска Telegram. Пока прокси
выключен, модуль не открывает порт, не создаёт фоновых задач и не обращается к
сети; TLS и буферы выделяются только после включения.
Прокси не требует установленного ядра zapret и работает независимо от его
стратегий. Встроенная реализация на Rust использует идею
[Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy), без Python,
отдельного процесса и скачивания движка. Код модуля входит в общий бинарник.

Поддерживаются abridged/intermediate/padded MTProto и прямые Telegram WSS
соединения с проверкой TLS-сертификатов; при разрешённом TCP fallback используется
обычный MTProto. Внешние CF-прокси, публичный доступ по LAN и Fake TLS не входят
в этот локальный модуль. Если медиа не загружаются, попробуйте оставить в DC
только `4:149.154.167.220` или очистить список.

## ❓ Частые вопросы

<details>
<summary><b>Антивирус блокирует ядро или его архив</b></summary>

<br/>

Ядра Windows используют драйвер перехвата пакетов WinDivert; антивирус может пометить такие компоненты как нежелательные. Сам факт предупреждения не позволяет определить, ложное ли оно. Проверьте источник файла и конкретное сообщение защиты. Для zapret2 установщик сверяет SHA-256 официального архива, манифеста и бинарных файлов; при блокировке или несовпадении установка завершается ошибкой. Собственного антивирусного сканирования в приложении нет; блокировка исходит от защиты Windows. Приложение не меняет настройки антивируса.

</details>

<details>
<summary><b>Почему приложение не использует GitHub API?</b></summary>

<br/>

У многих провайдеров `api.github.com` сам заблокирован DPI. Для Windows zapret1 версия берётся с `raw.githubusercontent.com`, архив — с `codeload.github.com`. zapret2 использует Atom-ленту и готовые release-файлы `bol-van/zapret2`, включая опубликованные контрольные суммы. На Mac используются Atom-лента релизов и готовый release-архив Flowseal; GitHub API также не нужен.

</details>

<details>
<summary><b>Где хранятся данные?</b></summary>

<br/>

На Windows конфиг лежит в `%APPDATA%\zapret-ui\config.toml`, ядра — в отдельных папках `zapret\` и `zapret2\`, логи — в `logs\` рядом с конфигом. Служба использует защищённую копию своего ядра в `%ProgramData%\zapret-ui\`. На macOS настройки GUI — в `~/Library/Application Support/zapret-ui/`, пользовательские списки ядра — в `~/Library/Application Support/ZapretMac/`. [Все пути macOS](docs/macos.md#пути-и-диагностика).

</details>

## 🛠️ Разработка и сборка

Общие UI и логика находятся в `ui/`, `src/app/`, `src/config.rs`, `src/telegram/` и других общих модулях. Интерфейсы в `src/ports.rs` связывают их с адаптерами ядер и системными функциями. Новые функции и исправления по умолчанию добавляются для обеих платформ; различия ограничены возможностями ядра и API операционной системы.

Нужен Rust из [`rust-toolchain.toml`](rust-toolchain.toml). На Windows установите MSVC Build Tools, на Mac — Xcode Command Line Tools. Общие проверки на любой из поддерживаемых систем:

```sh
cargo fetch --locked
cargo fmt --all -- --check
cargo clippy --frozen --all-targets --all-features -- -D warnings
cargo test --frozen --all-targets --all-features
cargo run --locked --example ui_only
```

`ui_only` запускает общий интерфейс с моками, без установки ядра и изменения сети. Обычные тесты не требуют администратора и внешней сети; первый `cargo fetch` загружает зависимости.

- **Windows:** `cargo build --locked --release` → `target/release/zapret-ui.exe`.
- **Mac:** `sh scripts/build-macos.sh` → `.app`, DMG, ZIP и контрольные суммы в `dist/`. [Подробности сборки и диагностики Mac](docs/macos.md).

Один CI проверяет и собирает обе платформы. Публикация по тегу `v*` происходит только после успеха обеих сборок: полный набор файлов сначала проверяется в черновике релиза. [Участие в разработке](CONTRIBUTING.md) · [Правила для агентов](AGENTS.md) · [Выпуск релиза](docs/RELEASING.md).
